# Telegram Price Tracker Bot

Простой Telegram-бот, написанный на Python, который отслеживает стоимость товаров на маркетплейсах и уведомляет пользователей об изменении цен с заданным интервалом.

## Возможности

- Мониторинг цен на товары по ссылке
- Интервальный опрос цен
- Уведомления в Telegram о снижении или повышении цены
- Поддержка нескольких пользователей и товаров
- Хранение токена и конфигурации в `.env` файле

## Пример использования

1. Пользователь отправляет ссылку на товар
2. Бот добавляет товар в отслеживание
3. Через заданный интервал бот проверяет цену
4. Если цена изменилась — пользователь получает сообщение

## Установка

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/AndNovv/marketplace_tgbot.git
cd marketplace_tgbot
```
### 2. Установите зависимости
```bash
pip install -r requirements.txt
```
### 3. Создайте .env файл
```env
TELEGRAM_BOT_TOKEN=your_bot_token
```
### 4. Запустите бота
```bash
python priceCheckerBot.py
```
